# Sternenwrack · Salvage Slots

**Aktuelle Version: Beta 0.9.0** · [Änderungsprotokoll](CHANGELOG.md)

Ein Sci-Fi-Spielautomat im Browser – **nur mit Spielgeld**, es geht um kein echtes Geld.

**Jetzt spielen:** https://heinr2ch.github.io/STERNENWRACK/

## Was dich erwartet

- Fünf Walzen, Freispiele, Bergungslaser mit Wild-Kristall und zwei Bonusspiele
- Ein rostiges Bergungsschiff, das du in fünf Bereichen ausbaust, mit Crew, Lackierungen und Expeditionen
- Sternenkarte mit vier Sektoren, Erfolge, Sammelalbum, Aufträge und Pilotenrang
- Rubbellose zum echten Freirubbeln, Tagesbonus und Signal-Risiko
- Erzeugte Synthwave-Musik in drei Titeln und Bip, der kleine Bordroboter

Der Spielstand wird im eigenen Browser gespeichert. Über das Bordbuch lässt er sich als Code mitnehmen.

Das ganze Spiel steckt in einer einzigen Datei: `index.html`.
